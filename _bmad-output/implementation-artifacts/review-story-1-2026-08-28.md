- [x] [Review][Patch] **Git-exclusion guard bypassed by alternate artifact spellings** — the resolver accepts both canonical and path-qualified keys, the guard only knows canonical: `resolve(PERSONAL, "private/telegram_cache/")` and `resolve(s, "transcripts/temp/")` return the same directories as `telegram_cache/`/`temp/` but `requires_git_exclusion(...)` answers False (verified by execution).
